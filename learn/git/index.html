the ten lessons.

#lessontimepasses when
1Set up Git and make a repositorySet user.name and user.email, make a cookbook folder, run git init -b main and read git status.10 min5 stepscookbook is a Git repository on a branch named main and user.name is set.
2Stage and commitWrite pancakes.md, stage it with git add and save it with git commit -m.15 min5 stepsThe repository has one commit and it adds pancakes.md.
3See what changed with log and diffChange the recipe twice, read git diff and git diff --staged, and commit each change.15 min5 stepsgit log shows three commits and git status reports a clean working tree.
4Undo a change and ignore filesThrow away a bad edit with git restore, unstage a file, and keep .DS_Store out with .gitignore.15 min6 steps.gitignore lists .DS_Store and is committed, and pancakes.md matches the last commit.
5Work on a branchAdd waffles.md on a branch named add-waffles with git switch -c while main stays as it was.15 min5 stepsThe add-waffles branch has one commit that main does not have.
6Merge a branchMerge add-waffles into main, read git log --oneline --graph and delete the branch.10 min5 stepsmain holds waffles.md and the add-waffles branch no longer exists.
7Fix a merge conflictChange the same line on main and on a branch, merge, read the conflict markers and commit the final text.20 min6 stepsThe last commit has two parents and no file holds conflict markers.
8Connect to GitHub with an SSH keyMake an ed25519 key with ssh-keygen, add it to your GitHub account and test it with ssh -T.20 min6 stepsssh -T git@github.com greets you by your GitHub user name.
9Push the cookbook to GitHubMake an empty repository on GitHub, link it with git remote add origin and push main.15 min5 stepsorigin points at GitHub and origin/main matches the local main branch.
10Open a pull requestPush a branch that adds syrup.md, open a pull request, read the diff, merge it and pull main.20 min6 stepsThe GitHub repository has one merged pull request and local main holds its commits.

miyagi builds each lesson when you ask for it, so your exact steps can differ.

then one project, alone.

A film list with a merged pull request

Start a new repository alone for a list of your favorite films. Make at least four commits, ignore .DS_Store, add one section on a branch and merge it through a pull request on GitHub.

passes when

  • The GitHub repository has at least four commits on main
  • One merged pull request came from a separate branch
  • A .gitignore is committed and git status reports a clean working tree
